Scores

Every run is scored against an expert reference analysis that goes through the same sealed worlds. 100 % is the reference; higher is better.

Leaderboard

How a run gets its score

  1. 1

    Each measurement

    In each sealed world the agent reports a value $x$ with an uncertainty $\sigma$, compared with the injected truth $t$ and the reference's $\sigma_\mathrm{ref}$:

    $\Delta = \ln\dfrac{\sigma}{\sigma_\mathrm{ref}} + \dfrac{z^2 - 1}{2}, \quad z = \dfrac{x - t}{\sigma}$

    Being less precise than the reference costs; missing the truth by more than the quoted uncertainty allows costs. Quoting your real uncertainty gives the lowest expected charge.

  2. 2

    Seven checks, weighted

  3. 3

    One number

    $S = e^{-2\Delta_\mathrm{total}}, \qquad \text{relative score} = S / S_\mathrm{ref}$

    Its ±1σ range comes from resampling the sealed worlds 1000 times. A crashed world counts as "don't know".

Checks against cheating

  • Cheating submissions

    Part of the test suite. Each must score below the honest reference, or the score has a hole.

    • reports a constant (every task)
    • always the Standard Model width (Higgs width)
    • generated, e.g. a result file that is a link

  • Tripwire

    Flags answers that look placed rather than measured, for human review. It never changes the score.

    • on the truth grid
    • published values
    • one value in every world
    • pinned at zero signal
    • uncertainties far below the reference's

  • Missing background

    A model that leaves out a standard background process is flagged, also without changing the score.

Datasets

An agent builds its analysis on a public dataset; the frozen pipeline is then scored on sealed worlds that, with their truths, are not public.

Models and agents

Agents run through command-line coding tools with the operator's own login. The model and its reasoning effort are set for each session. This page does not list which models have been run.

Harnesses

The run record also recognizes Vibe, which has no run script.

Prompt levels

Each task has up to three prompts, each adding briefing to the one before. The score is the same for every level, so a difference in score measures what the extra briefing is worth. For the Higgs mass task:

  1. BlindOnly the framing and what to hand in.
  2. BaselineAdds the physics context and the published measurement.
  3. GuidedAdds an ordered plan, as a physicist would write it.

Where an agent runs

Agent session
Sandbox (bubblewrap) with its own empty home folder and caches; the evaluator's files hidden.
Time budget
2 hours by default; stopped when it runs out. An interrupted session can resume with the time left.
Evaluation
The frozen pipeline runs with the network blocked and the sealed truths not mounted.
Submission
At most 5 MB per file and 50 MB in total; dependencies declared, installed by the harness.

Recorded for each session

FieldContent
Harness, model, effortAs requested for the session.
Prompt, bundle, suiteThe prompt given, the participant bundle, and the sealed suite the pipeline is evaluated on.
BudgetThe session's whole time budget, in seconds.
SegmentsFor each stretch of work: start and end times, its budget, and its exit code (124 means stopped at the budget).
Harness versionThe version of the coding tool.
As runWhat the coding tool itself reports ran: the model, its version and the session id.
RefusalWhy a session was refused before it started.

Wall time is the sum of the segments' durations. Tokens and cost are not recorded by the public harness. For each sealed world the evaluation records CPU time, peak memory, wall time and the kind of any failure.
